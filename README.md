# Fruit_Hub

A Mobile UI Kit Ecommerce named FruitHub

Fruit Hub is a mobile application offering the following features:

- Explore a variety of fresh fruit products
- View detailed product information
- Adjust quantities as needed
- Add products to the cart
- Manage the cart for easy checkout and delivery

You can download the .apk by checking the releases of this repository !
